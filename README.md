# SPSMC Build No Ores

Paper の `build` ワールドだけを対象に、自然生成された鉱石を石・深層岩へ置き換える小さなプラグインです。

通常地形のワールド生成を使うため、山・洞窟・バイオームなどは残ります。`resource`、`lobby`、その他のワールドは対象外です。

## 動作

- `build` ワールドの `WorldInitEvent` で `BlockPopulator` を登録します。
- 新しく生成されるチャンクの中央16×16ブロックを走査します。
- 自然生成された鉱石ブロックを次のように置き換えます。
  - 通常の鉱石 → `stone`
  - 深層岩の鉱石 → `deepslate`
- 既存チャンクの自動スキャンは行いません。
- プレイヤーが後から設置した鉱石は対象にしません。

`build` に既存チャンクがある場合、それらに残る鉱石を消すには別途バックアップ確認後の一度限りの掃除処理が必要です。

## ビルド

```sh
mvn clean package
```

生成物:

```text
target/spsmc-build-no-ores-0.1.0.jar
```

## 導入

生成したJARをPaperサーバーの `plugins/` に配置して再起動します。

このリポジトリの正本へ組み込む場合は、JARの配置方法と `plugin-urls.txt` またはDockerのビルド方法を別途決めてから反映します。
